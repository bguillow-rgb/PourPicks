Bottle pairing guides

84 curated pairings across 28 bourbons, each recorded with the reason it works.

Most pairing advice stops at "bourbon goes with steak." These guides work the other direction: start from one bottle's actual flavor profile, then name dishes that echo it — including the deep cuts worth trying once you have the obvious ones covered.

For the principles behind these matches rather than one bottle at a time, start with the bourbon food pairing guide. If you are working out what a bottle tastes like in the first place, the bourbon flavor wheel and how to write tasting notes cover the vocabulary these pages use.
